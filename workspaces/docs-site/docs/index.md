# Hees

Hees is an Incan-first structural admission boundary for governed AI proposals. An implementation supplies package
contracts and untrusted visible output. Hees can admit or reject that proposal using facts represented by its checked
types.

The current `0.0.1` preview proves two deliberately small surfaces:

1. descriptor-shape validation for an external source-controlled package; and
2. in-memory validation and proposal admission against package-owned actions and evidence identifiers.

These checks do not execute a model, retrieve content, open a descriptor path, parse JSON, verify a digest, determine
content rights, or prove that evidence semantically supports an answer. Those are future or caller-owned boundaries.

Start with [Getting started](getting-started.md), then use [Contracts](contracts.md) as the implemented reference.
