# Security policy

## Supported versions

Hees is pre-v0.1. Only the latest commit on the default branch is eligible for security fixes.

## Reporting a vulnerability

Use GitHub's private vulnerability-reporting feature for this repository. Do not open a public issue containing exploit
details, credentials, private package contents, or personal data.

Include the affected revision, a minimal fictional reproduction, impact, and any suggested mitigation. Maintainers will
acknowledge the report through the private channel and coordinate disclosure after a fix is available.

Structural admission is not a security proof of model output, source rights, semantic support, or package integrity.
